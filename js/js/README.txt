ANGRE / RULL TILBAKE

Denne ZIP-en inneholder bare den app.js-filen du lastet opp,
uten lønnsknapper og uten endringer i login.

Fil:
js/app.js

Bruk:
1. Pakk ut ZIP.
2. Kopier mappen js over i prosjektet ditt.
3. Behold din gamle index.html.
4. Trykk Ctrl + F5 i nettleseren.

Denne skal bare rulle tilbake JavaScript til slik app.js var da du lastet den opp.
